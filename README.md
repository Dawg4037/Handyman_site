# Handyman Website

Professional handyman services website serving Palm Harbor, Dunedin, and Tarpon Springs, Florida.

## Structure

- `index.html` - Main homepage (Palm Harbor focused)
- `tarpon-springs/index.html` - Tarpon Springs location page
- `sitemap.xml` - XML sitemap for search engines
- `robots.txt` - Search engine crawling instructions
- `CNAME` - GitHub Pages custom domain configuration

## SEO Features

- Schema.org LocalBusiness markup
- FAQ schema for rich snippets
- Open Graph and Twitter Card meta tags
- Geo meta tags for local SEO
- Semantic HTML5 structure
- Mobile-responsive design
- Fast-loading (no heavy frameworks)

- Secondary: handymantarponsprings.com (points to /tarpon-springs/)
